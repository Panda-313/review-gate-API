# Resetowanie hasła do konta

**Kategoria:** account  
**Tagi:** hasło, reset, logowanie, konto, e-mail

## Opis problemu
Klient nie pamięta hasła lub link do resetu nie działa / wygasł.

## Rozwiązanie
1. Na stronie logowania kliknij „Nie pamiętam hasła”.
2. Podaj adres e-mail powiązany z kontem.
3. Link resetujący jest ważny przez 60 minut.
4. Jeśli e-mail nie dotarł – sprawdź folder spam oraz poprawność adresu.
5. Po trzykrotnym nieudanym resecie konto może wymagać odblokowania przez support.

## Dodatkowe informacje
Nie resetujemy haseł ręcznie bez weryfikacji tożsamości. W przypadku kont firmowych reset może wymagać potwierdzenia przez administratora organizacji.
