# Wolno działający panel / dashboard

**Kategoria:** technical  
**Tagi:** wydajność, panel, wolne ładowanie, timeout

## Opis problemu
Panel ładuje się bardzo wolno, wykresy nie pojawiają się lub występują timeouty.

## Rozwiązanie
1. Poproś o przeglądarkę, system operacyjny oraz czy problem dotyczy wszystkich użytkowników organizacji.
2. Sprawdź status systemu (strona status / incydenty).
3. Zalec wyczyszczenie cache i wyłączenie rozszerzeń przeglądarki.
4. Duże konta z setkami tysięcy rekordów mogą wymagać zawężenia filtrów daty.
5. Jeśli problem dotyczy tylko jednego widoku – zbierz ID widoku / raportu i przekaż do zespołu technicznego.

## Dodatkowe informacje
Najczęstsze przyczyny po stronie klienta: słabe łącze, adblockery, bardzo szeroki zakres dat. Po stronie systemu – chwilowe przeciążenie generowania raportów.
